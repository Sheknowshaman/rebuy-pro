REBUY PRO MOBILE — V1.0

CONTENU
- index.html : application web responsive
- manifest.webmanifest : configuration installable PWA
- sw.js : cache des ressources essentielles
- icons/ : icônes de l'application

OUVRIR EN LOCAL
Vous pouvez ouvrir index.html pour tester l'interface. Certaines fonctions PWA (service worker et installation) nécessitent une adresse HTTPS ou localhost.

INSTALLER SUR IPHONE
1. Héberger le dossier complet sur un hébergement HTTPS.
2. Ouvrir l'adresse dans Safari.
3. Appuyer sur Partager > Sur l'écran d'accueil.
4. Activer « Ouvrir comme app web » si l'option apparaît.
5. Appuyer sur Ajouter.

LIMITES ACTUELLES
- Les estimations et l'historique sont stockés localement dans le navigateur.
- L'IA de reconnaissance photo n'est pas encore connectée : la photo est prévisualisée seulement.
- Le bouton IA prépare une consigne à copier dans Claude.
- Le cours de l'or tente une récupération via l'API publique Corgano et propose une saisie manuelle de secours.
- Pas encore de compte utilisateur ni de synchronisation cloud.
- Le cache hors ligne conserve l'interface, mais pas les recherches en ligne ni le cours de l'or en direct.

Ce prototype est un outil personnel non affilié officiellement à Cash Converters.
